# Event Info: Building from the Farm (SF Tech Week 2026)

Filtered from the event page. Source of truth: Partiful / MentorMates.

- **Host:** Stanford Founders Club, part of SF Tech Week 2026. Overnight, Stanford-only, 100–120 builders.
- **Partners:** ElevenLabs, Replit, World Labs, NVIDIA (free credits from each).
- **Theme:** Future of Work for Enterprise. Pick one track:
  - **Digital Twin:** simulated business/space to test changes before rollout.
  - **Company Brain:** capture institutional knowledge + detect when it goes stale.
  - **Customer Layer:** acquire, serve, keep customers (support, sales, onboarding, renewals). ← **Baseline's track**
- **Judging (all tracks):**
  1. Real improvement over the course of the build
  2. Quality relative to compute spent
  3. Robustness to edge cases not explicitly built for
  Top 5 teams present in the final round.
- **Teams:** encouraged to include at least one engineering student.
